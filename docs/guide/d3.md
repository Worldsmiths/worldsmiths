# D3

Minimal 3D author surface through `EngineServices.d3()`. Package: `io.github.worldsmiths.core.d3`. No LibGDX types in the contract.

Covers the D9b rollball set plus D3 P1: shared `Camera`, pose-only orthographic camera, Input-space pick-ray, primitive sphere/box creates, **async file mesh bind** after [`AssetKind.MESH`](assets.md) `COMPLETE`, instance material setters, and batch render. Proof sample: [`samples/mesh3d`](../../samples/mesh3d) (when present in the tree).

Deferred follow-ups (not this slice): procedural meshes (05d), custom shaders (05e), SceneCodec mesh bridge (05f), custom engine mesh format (05g), deeper `StandardMaterial` / albedo textures (05h), `.obj` / extra import formats (05i).

## Ownership / dispose

`D3` from the bag is a **factory**, not a disposable resource. Authors own dispose of every `Model` and `ModelBatch` they create (`model.dispose()`, `batch.dispose()` at shutdown).

For **`createModelFromLoaded`**: each successful bind returns a **new author-owned** `Model` wrapper (a second bind for the same path is another `Model`, not shared identity). On GDX backends the loaded glTF mesh also lives in a **private path→GPU registry** behind [`assets()`](assets.md); disposing your author `Model` drops your wrapper only — the registry entry stays until bag dispose tears down loads. Procedural models from `ModelBuilder` dispose the underlying GPU mesh as today.

These types need **no** dispose: `D3` itself, `Camera` / `PerspectiveCamera` / `OrthographicCamera`, `Environment`, `ModelBuilder`, `ModelInstance`, `Ray`, and `Vec3`.

## API

### Factory (`D3`)

| Method | Meaning |
| --- | --- |
| `createPerspectiveCamera(fovY, width, height)` | Perspective camera (FOV in degrees) |
| `createOrthographicCamera(viewportWidth, viewportHeight)` | Pose-only orthographic camera (world-unit viewport; no zoom / setToOrtho) |
| `createEnvironment()` | Lighting environment |
| `createModelBuilder()` | In-code primitive mesh builder |
| `createModelBatch()` | GPU batch (`begin` → `render` → `end`) |
| `createInstance(model)` | Drawable placement of a model (builder **or** file-loaded) |
| `createModelFromLoaded(path)` | Author-owned `Model` after MESH `COMPLETE`; new wrap per call; fail-closed before `COMPLETE` |

### Camera / lights / meshes / batch

| Type | Key methods |
| --- | --- |
| `Camera` | Shared pose + `update` + `getPickRay(screenX, screenY)` → immutable `Ray` |
| `PerspectiveCamera` | Extends `Camera`; `setNear` / `setFar` / `setPosition` / `setUp` / `lookAt` / `update` / `getPickRay` |
| `OrthographicCamera` | Extends `Camera`; same pose / pick surface (pose-only) |
| `Environment` | `setAmbientLight(r,g,b,a)` / `addDirectionalLight(r,g,b,dirX,dirY,dirZ)` |
| `ModelBuilder` | `createSphere(...)` / `createBox(...)` — RGBA diffuse; `createSphereEmissive` / `createBoxEmissive` — diffuse RGBA + emissive RGBA; position+normal attrs included |
| `Model` | `dispose()` (author-owned) |
| `ModelInstance` | Pose: `setTranslation` / `setTranslationAndScaling` / `setTranslationRotationScaling` (full overwrite; euler degrees X then Y then Z). Materials: `setDiffuse` / `setEmissive` (RGBA 0–1, **all mesh parts**, instance-local — siblings not affected) |
| `ModelBatch` | `begin(camera)` / `render(instance, environment)` / `end()` / `dispose()` (author-owned) |
| `Ray` / `Vec3` | Immutable pick math (`Ray.origin`, `Ray.direction`; public `x`/`y`/`z` floats) |

### File mesh bind

Only after [`assets().request(path, AssetKind.MESH)`](assets.md) reaches `LoadState.COMPLETE`:

```java
Model model = d3.createModelFromLoaded("meshes/hero.gltf");
ModelInstance inst = d3.createInstance(model);
inst.setDiffuse(1f, 0.85f, 0.2f, 1f);
inst.setEmissive(0.05f, 0.05f, 0.1f, 1f);
```

`createModelFromLoaded` throws `EngineException` when the path is blank/unknown or the handle is not yet `COMPLETE` — no silent null. Packaged **`.gltf` with external images** (not embedded-GLB-as-required). See [`Assets`](assets.md) for pump / hitch honesty on web.

### Input Y and pick-ray

`Camera.getPickRay(screenX, screenY)` takes **Input-space** screen coords: origin at the **top-left**, **Y down** — the same convention as `Input.getX()` / `Input.getY()`. Pass those values directly; do not flip Y for D3. Call `camera.update()` after pose changes before picking or `ModelBatch.begin`. Skipping `update` leaves pick / begin undefined.

Live GDX-backed cameras need a running graphics surface: viewport size comes from `Gdx.graphics`. If graphics is missing, the engine throws `EngineException` (fail-closed). `FakeD3` does not need graphics — use `seedPickRay` instead.

Each `getPickRay` returns a **fresh** immutable `Ray` (never a reused buffer). On Fake, that is a **copy** of the seeded ray (fields match the seed; not identity reuse). The game owns board-plane intersection; D3 does not project to cells.

### Board-plane intersect (author-owned)

```java
Ray ray = camera.getPickRay(services.input().getX(), services.input().getY());
// Example: hit horizontal board plane y = 0. Guard direction.y ≈ 0 in real code.
float t = -ray.origin.y / ray.direction.y;
float hitX = ray.origin.x + t * ray.direction.x;
float hitZ = ray.origin.z + t * ray.direction.z;
// Map hitX/hitZ to a cell in game space.
```

## Usage

### Primitives (rollball-style)

```java
private EngineServices services;
private ModelBatch batch;
private Environment environment;
private PerspectiveCamera camera;
private Model ballModel;
private ModelInstance ballInstance;

public void create(EngineServices services) {
  this.services = services;
  D3 d3 = services.d3();
  ModelBuilder builder = d3.createModelBuilder();
  ballModel = builder.createSphere(1f, 1f, 1f, 24, 24, 0.2f, 0.55f, 0.95f, 1f);
  ballInstance = d3.createInstance(ballModel);
  batch = d3.createModelBatch();
  environment = d3.createEnvironment();
  environment.setAmbientLight(0.45f, 0.45f, 0.45f, 1f);
  environment.addDirectionalLight(0.85f, 0.85f, 0.8f, -0.6f, -1f, -0.3f);
  camera = d3.createPerspectiveCamera(
      67f, services.graphics().getWidth(), services.graphics().getHeight());
  camera.setNear(0.1f);
  camera.setFar(100f);
}

public void render() {
  ballInstance.setTranslationAndScaling(x, y, z, 1f, 1f, 1f);
  camera.setPosition(eyeX, eyeY, eyeZ);
  camera.setUp(0f, 1f, 0f);
  camera.lookAt(lookX, lookY, lookZ);
  camera.update();
  batch.begin(camera);
  batch.render(ballInstance, environment);
  batch.end();
}

public void dispose() {
  batch.dispose();
  ballModel.dispose();
}
```

Hold the bag from `create(EngineServices)`. Pair every `begin` with `end`. Dispose author-created models and the batch at shutdown — not the bag's `D3`.

### Async glTF + tint (mesh3d pattern)

```java
private LoadHandle meshHandle;
private Model fileModel;
private ModelInstance meshInst;

public void create(EngineServices services) {
  this.services = services;
  D3 d3 = services.d3();
  batch = d3.createModelBatch();
  environment = d3.createEnvironment();
  camera = d3.createPerspectiveCamera(
      67f, services.graphics().getWidth(), services.graphics().getHeight());
  meshHandle = services.assets().request("meshes/demo.gltf", AssetKind.MESH);
  meshHandle.onTerminal(() -> {
    if (meshHandle.state() == LoadState.COMPLETE) {
      fileModel = d3.createModelFromLoaded("meshes/demo.gltf");
      meshInst = d3.createInstance(fileModel);
    }
  });
}

public void render() {
  if (meshInst == null) {
    return;
  }
  meshInst.setTranslationAndScaling(0f, 0f, 0f, 1f, 1f, 1f);
  camera.update();
  batch.begin(camera);
  batch.render(meshInst, environment);
  batch.end();
}

public void dispose() {
  batch.dispose();
  if (fileModel != null) {
    fileModel.dispose();
  }
}
```

Toggle `meshInst.setDiffuse(...)` / `setEmissive(...)` in `update` for a visible material change. `samples/mesh3d` exercises this path on desktop and web.

### Orthographic + emissive + TRS (P1)

```java
OrthographicCamera camera = d3.createOrthographicCamera(12f, 12f);
camera.setPosition(0f, 10f, 0f);
camera.setUp(0f, 0f, -1f);
camera.lookAt(0f, 0f, 0f);
camera.setNear(0.1f);
camera.setFar(100f);
camera.update();

Model beam = d3.createModelBuilder()
    .createBoxEmissive(0.1f, 0.1f, 2f, 1f, 1f, 1f, 1f, 1f, 0.4f, 0.1f, 1f);
ModelInstance inst = d3.createInstance(beam);
inst.setTranslationRotationScaling(0f, 0.05f, 0f, 0f, 45f, 0f, 1f, 1f, 1f);

batch.begin(camera);
batch.render(inst, environment);
batch.end();

Ray ray = camera.getPickRay(services.input().getX(), services.input().getY());
```

Diffuse `createSphere` / `createBox` stay unchanged. Emissive creates take the same geometry + diffuse RGBA, then emissive `er, eg, eb, ea`. Runtime `setDiffuse` / `setEmissive` on instances apply on top of loaded or procedural meshes (parameterized tint only in this slice — not PBR textures; see 05h).

## Tests

`FakeEngineServices.d3()` returns a recording `FakeD3`: inspect `commands()`, `batchDisposed()`, and `modelsDisposed()` without a GPU. Expect `CREATE_MODEL_FROM_LOADED`, `SET_DIFFUSE`, `SET_EMISSIVE` after MESH complete + bind. Seed pick returns with `seedPickRay` before `getPickRay` (empty seed throws `EngineException`). Each Fake `getPickRay` returns a fresh `Ray` whose fields match the seed.

Pair with `FakeAssets.putMesh(path)` + `pump()` before `createModelFromLoaded`. Sample sync helpers may still skip `create()`; prefer FakeD3 when asserting the create/render path.
